# Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing customer shopping behavior using **Python, MySQL, SQL, Power BI, and DAX**.

The project transforms raw transactional data into business insights through data preparation, database integration, SQL analysis, and an interactive four-page Power BI dashboard.

---

## 📌 Project Overview

The objective of this project is to analyze customer purchasing behavior and identify patterns in:

* Customer spending
* Product and category performance
* Customer loyalty
* Subscription behavior
* Discount usage
* Purchase frequency
* Payment and shipping preferences
* Revenue contribution across customer groups

The final deliverable is an interactive **four-page Power BI dashboard** designed to help business users explore customer behavior and revenue drivers.

* Gender

### Purchase Information

* Item Purchased
* Category
* Purchase Amount
* Season
* Size
* Color

### Shopping Behavior

* Discount Applied
* Promo Code Used
* Previous Purchases
* Frequency of Purchases
* Review Rating
* Shipping Type
* Payment Method

The dataset initially contained **37 missing values in the Review Rating column**.

---

## 🐍 Data Preparation — Python

Python and pandas were used for the initial data preparation process.

### Data Exploration

* Loaded the dataset using pandas.
* Used `head()`, `info()`, and `describe()` for initial exploration.
* Checked missing values using `isnull().sum()`.

### Missing Value Treatment

Missing review ratings were filled using the **median review rating within each product category**.

### Column Standardization

Column names were standardized to lowercase `snake_case` format for easier use across Python, SQL, and Power BI.

### Feature Engineering

Two features were created:

* **Age Group** — customers grouped using age quartiles.
* **Purchase Frequency Days** — purchase frequency categories converted into numerical day values.

### Data Consistency

`promo_code_used` was identified as redundant with `discount_applied` and was removed from the cleaned dataset.

## 🗄️ MySQL Database Integration

* PyMySQL

## 🔎 SQL Business Analysis

SQL was used to answer **10 business questions**.

### Questions Analyzed

1. Compare total revenue generated by male and female customers.
2. Identify customers who used discounts but still spent above the overall average purchase amount.
3. Identify the top 5 products based on average review rating.
4. Compare average purchase amount between Standard and Express shipping.
5. Compare subscriber and non-subscriber customer count, average spending, and total revenue.
6. Identify the 5 products with the highest percentage of discounted purchases.
7. Segment customers into New, Returning, and Loyal based on previous purchases.
8. Identify the top 3 most-purchased products within each category.
9. Analyze repeat buyers with more than 5 previous purchases by subscription status.
10. Compare total revenue contribution across customer age groups.

SQL techniques used include:

* `GROUP BY`
* Aggregate functions
* `CASE`
* Subqueries
* `ORDER BY`
* `LIMIT`
* Common Table Expressions (CTEs)
* Window functions
* `ROW_NUMBER()`

## 🧮 DAX Measures

Core DAX measures created for the dashboard include:

```DAX
No. of customers =
COUNT('customer_behaviour customer'[customer_id])
```

```DAX
Avg purchase amount =
AVERAGE('customer_behaviour customer'[purchase_amount])
```

```DAX
Avg review rating =
AVERAGE('customer_behaviour customer'[review_rating])
```

Additional measures were created to support revenue, discount, subscription, and purchase-frequency analysis.
